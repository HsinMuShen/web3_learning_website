Ethereum is a blockchain platform that allows developers to create and run decentralized applications (dApps) using smart contracts.

## Simple Explanation

If Bitcoin is like digital gold, Ethereum is like a global computer. While Bitcoin is mainly for sending money, Ethereum lets you build entire applications that run on the blockchain.

## Key Features

- **Smart Contracts**: Programs that run automatically
- **Decentralized Apps**: Applications with no central control
- **Ether (ETH)**: The native cryptocurrency used for transactions
- **Programmable**: Developers can build on top of it

## Created By

Vitalik Buterin proposed Ethereum in 2013, and it launched in 2015.
