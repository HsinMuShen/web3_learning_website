## 🔄 Keeping Docs Updated

When creating new documentation:
1. ✅ **Place it in this `docs/` folder** (not project root)
2. ✅ **Update this README** with a link to the new doc
3. ✅ **Use descriptive filenames** (e.g., `FEATURE_NAME_PLAN.md`)
4. ✅ **Include date** in document header
5. ✅ **Link to related docs** where relevant
